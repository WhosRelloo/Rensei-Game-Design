# Scripts (exported from Studio)

Read-only copies of Luau scripts from the Rensei Studio place, saved here so changes can be reviewed on GitHub. **The Studio place is the source of truth**; these files are not synced automatically, and editing them here changes nothing in the game.

Paths mirror the Studio tree (`Scripts/ServerScriptService/MinigameService.lua` = `game.ServerScriptService.MinigameService`). Files ending `.server.lua` are Scripts, `.client.lua` LocalScripts; the rest are ModuleScripts. `MainMenu/` and `Tutorial/` hold scripts from those two places (same layout); shared modules are exported once, from Ye.
